# obshug
Obsidian to Gohugo skript to move and modify md files from ObsidianMD directory to Hugo directory.


## Usage

- Modify settings.toml file to correspond to your directory locations
- Run obshug.py
-   python3 obshug.py
```

> [!CAUTION]
> Skript is replaicing files in moving operation. Make sure you know what you do!!
